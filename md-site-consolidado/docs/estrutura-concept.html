Manifesto

PRINCÍPIOS 01 — nada decorativo sobrevive
02 — a régua é o elemento
03 — mono expõe o dado
04 — o movimento carrega sentido
05 — o vazio é 60% do projeto

RESTRIÇÕES sem radius
sem sombra difusa
sem gradiente
uma cor de acento — só uma

A maior parte da página é vazio. Isso não é ausência de projeto: é a condição para que a linha preta de 2px signifique alguma coisa quando aparece.

Do brutalismo pegamos a honestidade — a grade fica exposta, o dado técnico fica em mono, a borda não pede desculpa.

Do cinético pegamos o tempo. Nenhum elemento aqui é estático: o marquee lê a velocidade do seu scroll, o título se afasta do cursor, a régua avança conforme você desce. A interface só termina de existir enquanto você a usa.

[ 03 ]

Capacidades

SRV / 01

Sistema visual

Tokens, escala tipográfica, régua de espaçamento e regras de contraste documentadas em arquivo único.

SRV / 02

Interface

Telas construídas sobre grade exposta, com estados e vazios definidos antes do preenchimento.

SRV / 03

Motion

Curvas de easing próprias, reação a scroll e ponteiro, animação atrelada a dado real e não a enfeite.

SRV / 04

Front-end

Entrega em HTML, CSS e JS puro. Zero dependência, zero build, arquivo que abre em qualquer lugar.

SRV / 05

Editorial

Ritmo de leitura, hierarquia por escala e uso de metadado técnico como elemento gráfico.

SRV / 06

Direção

Definição de território visual e das restrições que o projeto vai respeitar até o fim.

[ 04 ]

Processo

01

Reduzir antes de desenhar

Listamos tudo que o projeto pede e cortamos até doer. O que sobrevive ao corte é o que vira estrutura.

DURAÇÃO ~ 1 SEMANA
02

Levantar a estrutura crua

Grade, régua, escala e hierarquia em preto no branco. Nenhuma cor, nenhum efeito, nenhuma imagem ainda.

DURAÇÃO ~ 2 SEMANAS
03

Dar tempo aos elementos

Definimos como cada peça entra, reage e sai. O movimento é especificado com a mesma precisão de um espaçamento.

DURAÇÃO ~ 2 SEMANAS
04

Entregar em arquivo único

Código autocontido, comentado por seção, sem build e sem dependência externa. Abre no navegador e funciona.

DURAÇÃO ~ 1 SEMANA
